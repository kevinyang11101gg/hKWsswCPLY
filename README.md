# Python外卖配送分析与可视化系统

## 核心功能
- 用户登录注册
- 美食数据可视化大屏
- 美食信息展示
- 美食数据管理
- 公告资讯查看
- 商品详情浏览
- 立即购买
- 加入购物车
- 美食评论功能
- 美食分类浏览
- 订单管理
- 订单配送管理
- 用户管理
- 美食管理
- 美食分类管理

## 适用场景
- 外卖配送公司
- 美食平台运营
- 数据分析师
- 企业决策者

## 技术特点
- 基于Django框架构建，确保系统稳定性和扩展性
- 利用MySQL数据库进行数据存储和管理
- 采用Vue.js进行前端页面开发，提升用户体验
